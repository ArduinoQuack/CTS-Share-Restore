# Security policy

## Supported version

Security fixes are provided for the latest release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for a vulnerability that could expose selected content, private files, or elevated/root access.

Include the affected version, device and Android version, module framework, reproduction steps, impact, and a minimally redacted log. Do not send account credentials, private signing keys, full Google APKs, or personal selected content.

This project runs inside the Google app process through an Xposed-compatible framework. Treat third-party builds and modified APKs as untrusted unless you can audit and reproduce them.
